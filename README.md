# GMT458 Web GIS



This project was prepared for the GMT 458 Web GIS Assignment 1.



## Project Description



This project is a personal Web GIS website developed using HTML, CSS, OpenLayers and Leaflet.



The website contains several pages, including:



* Background

* Projects

* Maps



The Maps page includes interactive OpenLayers and Leaflet maps centred on Ankara.



## Technologies Used



* HTML

* CSS

* JavaScript

* OpenLayers

* Leaflet



## Web GIS Features



The project includes:



* An interactive OpenLayers map

* An interactive Leaflet map

* Map markers around Ankara

* A zoom threshold for displaying markers

* A solution to prevent the map from repeating the world when zoomed out

* A table containing project information and map images

* CSS animation



## AI Usage



During the development of this project, AI was used to help understand HTML, CSS, JavaScript, OpenLayers and Leaflet, and to troubleshoot problems encountered during development.



One specific thing I learned from AI was how to use a zoom threshold so that map markers are displayed only after the user zooms in to a specified level. I also learned how to prevent the map from repeating the world when zooming out.



Estimated total AI usage: approximately 2 hours.
